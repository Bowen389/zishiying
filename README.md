# 四象限首板策略

工作流按北京时间工作日 17:06 和 17:36 扫描，09:31 和 09:41 筛选开盘缺口。遇休市跳过。实际启动时间由 GitHub Actions 调度。可手动补扫指定盘后日期或执行当天开盘筛选。报告在 `reports/YYYY-MM-DD.md` 及 `reports/opening/YYYY-MM-DD.md`，盘后特征保存在 `state/`。仅发布研究信号。

## 策略和数据口径

- R4 沿用「仅放宽 R4」的次日缺口 `[-6.5%, -2.2%)`、复合分排序和排名第二须达到首板成交额中位数 2 倍。历史对照 199 笔、净盈亏 +¥50,850。
- 日线使用通达信交易日行情包，上证指数与开盘取腾讯行情，R1/R2 必要的换手取东方财富历史数据。宽度统计日包内有效沪深京 A 股，北交所日包缺失时报告标明沪深口径。
- 重建口径采用当日有效非一字主板首板池计算总体标准差 Z 分数。成交额取自然对数，倍量比为相较上一交易日成交量，涨停热度为当日主板非 ST 涨停数除以前 20 日均值，VWAP 增幅为收盘相对成交额除成交量的涨幅。近 20 日成交额中位数排除信号日。
- B 在 R1–R3 主策略开盘零入选时启用，以至少 34 根历史有效日线作为上市满 35 个交易日的保守代理。在量比前 50% 中按开盘缺口从低到高取一只。旧报告里 B 的额外市场门控未恢复，当前 B 使用象限门控。
- 当前为重建试运行口径，尚无逐笔数据证明与历史 199 笔相同。研究时点为 T+1 开盘筛选、T+2 收盘退出。
